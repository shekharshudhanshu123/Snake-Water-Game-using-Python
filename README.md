# 🐍 Snake Water Gun Game

My first Python project — a simple **Snake-Water-Gun game** where you play against the computer.

## 🎮 How to Play

Enter one of the following choices:

- `s` → Snake 🐍
- `w` → Water 💧
- `g` → Gun 🔫

The computer randomly selects its choice, and the program determines whether you **win, lose, or draw**.

## 🛠️ Technologies Used

- **Python**
- `random` module
- Dictionaries
- Conditional statements
- User input
- f-strings

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python snake_water_gun.py
```

## 📌 Example

```text
Enter your choice: s
You chose snake
Computer chose water
You win
```

## 🎯 Learning Objective

This project helped me practice **Python basics, dictionaries, random selection, user input, and if-elif-else conditions** by creating a simple interactive game.
